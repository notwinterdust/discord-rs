v0.1.0 Released — Pure Standard Library

The Discord Framework built with Pure Rust Std

Zero async runtimes. Zero third-party bloat. Strict #![forbid(unsafe_code)]. High-throughput gateway sharding and type-safe REST clients implemented using standard threads, atomics, and channels.

$ cargo add discord-rust

Designed from First Principles

Built for predictability, minimal binary size, and zero unexpected dependencies.

Standard Library Only

No complex async/await state machines or bloated tokio dependency trees. Leverages native OS threads, lockless atomics, and std::sync::mpsc channels.

Strictly Unsafe-Free

Every single crate in the workspace explicitly enforces #![forbid(unsafe_code)]. Guaranteed memory safety across all models, parsers, and runtimes.

Pluggable Transports

Gateway and REST connections are decoupled behind traits. Seamlessly plug in native TLS, tungstenite, or mock test harnesses without changing application logic.

Auto Sharding Runtime

Built-in multi-shard orchestrator queries Discord's recommendation endpoint and coordinates concurrent workers across CPU cores with automated heartbeat management.

Thread-Safe LRU Cache

Per-type caching for Guilds, Channels, Members, Users, Roles, and Messages. Automatically populates and invalidates state from incoming Gateway events.

Granular Modularity

14 focused sub-crates (models, clients, voice, webhook, app commands, etc.) allow applications to pull only the components they need, or use the unified discord-rust facade.
