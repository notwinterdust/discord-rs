The Modern Discord Framework for Rust

High-performance gateway sharding, typed commands, real-time voice, and ergonomic REST clients built for speed, predictability, and rock-solid reliability.

$ cargo add discord-rust

Designed from First Principles

Built for predictability, minimal binary size, and zero unexpected dependencies.

Bounded Thread Pool

Fixed-size worker pool with configurable thread count, graceful shutdown, and live introspection. Powers PooledEventDispatcher for concurrent parallel event fan-out across CPU cores.

Type-Safe Architecture

Strongly-typed domain models, Snowflakes, bitflags, and permission checks validate payloads at compile time to eliminate runtime surprises.

Proc Macro #[command]

Annotate any Rust function with #[command] and get a fully-typed CommandDefinition with auto-extracted arguments, aliases, and descriptions — zero boilerplate.

Auto Sharding Runtime

Built-in multi-shard orchestrator queries Discord's recommendation endpoint and coordinates concurrent workers across CPU cores with automated heartbeat management.

Cache & Edit Tracking

Per-type caches for Guilds, Channels, Members, Messages, and Presences. MessageEditTracker bidirectionally maps user commands to bot responses for seamless edit-aware replies.

FFmpeg Audio Streaming

FfmpegSource spawns an ffmpeg child process and streams 48 kHz stereo PCM frames directly into the voice RTP pipeline — files, URLs, or any custom child process.
